# Student Habit Tracker

Personalni dashboard za studente da prate svoje navike, učenje i svakodnevne aktivnosti.

## O projektu

Ovo je Angular aplikacija razvijena kao projekat za predmet Web programiranje. Ideja je bila napraviti nešto korisno za studente,mjesto gdje mogu pratiti sve svoje aktivnosti i vidjeti napredak.

## Šta ima unutra

- **Dashboard** - glavni pregled, biraju se 3 trackera koje želite oratiti
- **Chatbot** - asistent koji pomaže i daje savjete
-  **Kalendar**

## Tech stack

- Angular 19
- TypeScript
- Chart.js za grafikone
- LocalStorage za podatke
- CSS za stilove
- Standalone komponente


Može se registrovati sa bilo kojim emailom i lozinkom. Podaci se čuvaju lokalno u browseru.

Svaki tracker ima svoju karticu i mogu se organizovati. Kalendar je desno za pregled.

Grafikoni pokazuju:
- Sate spavanja kroz vrijeme
- Sate učenja
- Raspoloženje
- Unos vode
Mogu se filtrirati po sedmici, mjesecu ili custom danima.

###Chatbot
Mali robot u donjem desnom uglu. Klikom na njega i možeš pitati o navikama, tražiti savjete itd. Radi bez API-ja, sve je lokalno.
